# 要件定義

## 1. 目的
個人のタスクを登録・管理し、期限や進捗を把握できるようにする。

## 2. 利用者
- 一般ユーザー（ログインして自分のタスクを管理する）

## 3. 機能要件
| No | 機能 | 概要 | 優先度 |
| --- | --- | --- | --- |
| 1 | タスク一覧 | 自分のタスクを一覧表示 | 必須 |
| 2 | タスク登録 | タイトル・詳細・期限・優先度を登録 | 必須 |
| 3 | タスク編集 | 登録内容を変更 | 必須 |
| 4 | タスク削除 | タスクを削除 | 必須 |
| 5 | ステータス変更 | 未着手 / 進行中 / 完了 | 必須 |
| 6 | ログイン / ログアウト | | 必須 |
| 7 | ユーザー登録 | | 必須 |
| 8 | 検索・絞り込み | キーワード・ステータス・期限 | 任意 |
| 9 | 並び替え・ページング | | 任意 |

## 4. 非機能要件
- （例）パスワードはハッシュ化して保存する
- （例）他ユーザーのタスクは参照・操作できない
