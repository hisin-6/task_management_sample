## 学んだこと

- Spring Initializrの初期設定は、その時点の最新版。今回は4.1が選択され、plan.mdに書いたSpring Boot 3よりサポート期間が長いため、そのまま4.1を採用
- Gradle Wrapperの役割。`gradlew` と `gradle-wrapper.jar` をコミットしておけば、Gradleを入れていない環境でも同じバージョンでビルド可能
- Dockerコマンドの実行場所。`sudo service docker start` はどこで実行しても同じ結果で、`docker compose up` は `compose.yaml` があるフォルダでの実行が必要
- `.gitignore` で除外するもの。`build/` と `.gradle/` の生成物や、`.vscode/` などのエディタの個人設定はコミット対象外
- 設定ファイルに書くパスワードの扱い。ローカル専用の開発用パスワードならコミットしても問題なし。本番用は環境変数から読み込む形にする予定

## 詰まったこと・解決方法

- SDKMANのインストールが `unzip` 不足で失敗。`sudo apt install unzip zip` で解決
- `docker compose up` で、Dockerのデーモンが起動していないというエラー。このWSLはsystemdが動いていないため、`sudo service docker start` で手動起動して解決
- イメージのダウンロード時に `docker-credential-desktop.exe` が見つからないというエラー。以前使っていたDocker Desktopの設定が `~/.docker/config.json` に残っていたことが原因で、`credsStore` の設定を消して解決
