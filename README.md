# タスク管理アプリ（学習用）

Java + Spring Boot で作るタスク管理アプリ。

## フォルダ構成
```
task_management_sample/
├── README.md
├── app/                  # Spring Boot アプリ本体（1週目に Spring Initializr で生成）
└── docs/
    ├── plan.md           # 1か月の学習計画（週ごと）
    ├── requirements.md   # 要件定義
    ├── design/           # 画面設計・ER図など
    └── daily-report/     # 日報（_template.md をコピーして使う）
```
